# DAEVEXUS faction scenes

Created for Home sections 2 (Elyos) and 3 (Asmodians), and their existing `/elyos` and `/asmodians` pages.

## Assets

| Faction | Repository asset | Native dimensions |
| --- | --- | --- |
| Elyos | `public/home/daevexus-elyos-scene.webp` | 1672 × 941 |
| Asmodians | `public/home/daevexus-asmodians-scene.webp` | 1672 × 941 |

The built-in image generation tool created both scenes. The source PNGs were converted to WebP at quality 95 without resizing, cropping, or upscaling. A 3840 × 2160 output was requested in the prompts; the returned images are 1672 × 941 and are not described as native 4K.

The approved first Home image was used only as a visual reference. Its asset, hero markup, image positioning, hotspots, and existing styles must remain unchanged.
